🛍️ Cartão de Produto Responsivo

📌 Sobre o Projeto

Componente de cartão de produto desenvolvido com HTML5 e CSS3, inspirado em um desafio do Frontend Mentor. Possui layout moderno, responsivo e foco na usabilidade.

🎯 Funcionalidades

✅ Design Responsivo com imagens adaptáveis para desktop e mobile
✅ Estilização Limpa com uso de fontes personalizadas e variáveis CSS
✅ Botão Interativo com ícone de carrinho e feedback visual
